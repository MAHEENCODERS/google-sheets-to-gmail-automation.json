# Google Sheets to Gmail Automation

## Workflow
Google Sheets Trigger → Get Row → IF → Send a Message → Update Row

## Purpose
This workflow monitors Google Sheets for new rows, checks the row using an IF condition, sends an email through Gmail when the condition is met, and then updates the corresponding row in Google Sheets.

## Nodes
1. Google Sheets Trigger
2. Get row(s) in sheet
3. IF
4. Send a message
5. Update row in sheet
